🛠 Installation & Development

Clone the project:

```bash
git clone https://github.com/osos3lom/osamaportfolio.git
cd osamaportfolio
```

Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Start development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open:

👉 [http://localhost:3000](http://localhost:3000)

Start editing pages inside:

```
app/[lang]/page.tsx
```

The app automatically hot-reloads as you save.

The project is ready to deploy using **Vercel**, the official hosting platform for Next.js.

2. Import your GitHub repository
3. Deploy with one click
